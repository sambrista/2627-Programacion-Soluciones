## Compilación y ejecución

La versión de Java que usamos es **Java 25 (LTS)**. Los programas usan el método `main` simplificado (sin `static` ni parámetros), por lo que necesitan **JDK 25 o superior**. Se puede comprobar la versión instalada con:

```
java -version
```
### Compilar y ejecutar

Primero se compila con `javac`, lo que genera el fichero `.class`, y después se ejecuta indicando el nombre de la clase (sin extensión):

```
cd UT1\Funciones
javac Funciones20.java
java Funciones20
```

> En Linux y macOS las rutas se escriben con `/` en lugar de `\`.
